The application is a centralized management and networking platform designed to streamline the operations and growth of university student club - DNS. It addresses the common challenge of fragmented communication by providing a single hub for internal organization and external outreach.



ScopeImprove club management through automated attendance tracking, event creation by administrators using a content management system (e.g., Strapi), mobile notifications before events (e.g., in the morning before an event), and attendance report generation in CSV format.

The system should also support creating project teams, assigning members to them, searching for teams by tags, and applying to join a team.
